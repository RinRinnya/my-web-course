# HW-04 — Налаштування VS Code та npm

У цьому завданні було налаштовано npm та встановлено Prettier для автоматичного форматування коду. Створено конфігураційний файл `.prettierrc` та додано npm-скрипти `format` і `format:check`.

Для форматування всіх файлів потрібно виконати `npm run format`, а для перевірки форматування — `npm run format:check`.
