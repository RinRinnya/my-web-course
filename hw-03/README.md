
# HW-03 — Git & GitHub Project

Цей проєкт створено в межах навчального курсу з веброзробки.

## Структура проєкту

- `index.html` — головна сторінка.
- `about.html` — інформація про автора.
- `projects.html` — список навчальних проєктів.
- `css/style.css` — стилі сайту.
- `js/main.js` — JavaScript-код.
- `images/` — зображення проєкту.

## Використані технології

HTML5, CSS3, JavaScript, Git та GitHub.

## Навігація

Між сторінками сайту можна переходити за допомогою меню.
